# html-tool-sample（見積もり計算）

飲食店や小さなお店向けの、見積もり計算ツールの見本です。HTML1ファイル（`index.html`）だけで動き、ブラウザで開くだけで使えます。外部への通信・外部ライブラリ・CDN（外部の配信サーバー）は使っていません。

## 何ができるか

- 品目・数量・単価を入力すると、金額と小計が自動で出る（最大30行）
- 値引き（円）を引き、税率（10%または8%）をかけて税込合計を出す
- 明細をテキストでコピーする（メールや書類に貼る用）
- 印刷する（ボタン類は印刷に出ない）
- 入力内容をこのブラウザの中に保存する（任意。保存できない環境では保存せずに計算だけ動く）

入力項目は5つです：品目、数量、単価、値引き、税率。

## 使い方

1. `index.html` をブラウザで開く（ダブルクリックでよい）。
2. 品目・数量・単価を入れる。行が足りなければ「行を追加」。
3. 値引きと税率を選ぶと、税込合計が出る。
4. 「明細をコピー」で明細をコピー、「印刷」で印刷する。
5. 「入力を空にする」で最初からやり直せる。

## 計算のきまり（この見本の仮の決め方）

- 数量と単価は0以上の整数として扱う（小数・負の値・文字は0または切り捨て）。
- 値引きは小計を超えない（超えた分は小計までに丸める）。
- 消費税は「（小計 − 値引き）× 税率」を1回計算し、1円未満を切り捨てる。
- 税率は1つの見積もりに1つだけ（10%と8%の混在は扱わない）。

実際の業務で使う計算式（端数処理、税率の混在など）は、お客様が文章で決める想定です。

## 保証しないこと

- 計算式が、お使いの業務・会計・税務の取り決めに合っているかは保証しません。
- ほかのサイトに埋め込んだときのCSS（見た目の指定）の衝突は保証しません。
- 保存機能はブラウザごとの記録です。ブラウザのデータを消すと消えます。別のパソコンには移りません。
- 請求書・納品書として法令の要件を満たすかは保証しません（このツールは見積もりの計算と明細の整形だけです）。
- 「明細をコピー」は、ブラウザの設定によってはコピーできないことがあります（下の確認状況を参照）。
